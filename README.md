## 📌 Sobre o Projeto

Esta landing page foi planejada e desenvolvida com foco em **UI/UX moderna, desempenho e conversão**. O objetivo principal é apresentar os serviços de uma clínica estética (lentes de contato, alinhadores e clareamento) de forma elegante e conduzir o usuário para um agendamento rápido via WhatsApp.

### ✨ Funcionalidades
* **Design Responsivo:** Adaptável para dispositivos móveis, tablets e desktops.
* **Foco em Conversão (CTA):** Botões estratégicos e botão flutuante de WhatsApp fixo.
* **FAQ Interativo:** Sistema de dúvidas frequentes em estilo sanfona (*accordion*) feito em JavaScript nativo.
* **Carregamento Rápido:** Construído em arquivo único leve, otimizado para performance.
* **Ícones e Tipografia Moderna:** Integração com Font Awesome e Google Fonts (*Plus Jakarta Sans*).

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estrutura semântica e acessível.
* **CSS3 / Tailwind CSS:** Estilização moderna e layout flexível (Grid/Flexbox).
* **JavaScript (ES6+):** Interatividade do menu e componentes dinâmicos (FAQ).
